## Known-Correct API Values

- CatBoost `loss_function` for binary log-loss classification is `'Logloss'` — capital L, no underscore, no other capitals. `'Log_loss'` and `'LogLoss'` will error.
- CatBoostClassifier DOES support a `class_weights` parameter directly (unlike some earlier belief) — pass it as a list ordered by class index: `class_weights=[weight_for_0, weight_for_1]`. Do not substitute `scale_pos_weight` instead — it implements a different formula and will not match a prompt's explicit class_weights specification. If you're unsure whether a parameter exists, check with `CatBoostClassifier().get_params()` or the actual error message rather than assuming a limitation.
- To retrieve per-iteration train/validation metric history from a fitted CatBoost model, use `model.get_evals_result()` — returns `{'learn': {'Logloss': [...]}, 'validation': {'Logloss': [...], 'AUC': [...]}}`. Do not guess at alternative method names (`get_fold_iterations_logloss`, `get_eval_metrics`, `get_fold_iterations_mse`, etc.) — these are not standard CatBoost methods. If unsure of a method name, check `dir(model)` or read the actual error message before retrying with another guess.
- If a library call fails on a parameter's string value, do not guess more than twice. If you can't determine the correct value from the error message, stop and say so explicitly — do not silently substitute a different parameter that changes what was actually asked for (e.g. swapping loss functions changes the comparison being requested, not just the syntax).
- sklearn's fitted `DecisionTreeClassifier.tree_` object has no `n_samples` attribute — the correct attribute for per-node sample counts is `n_node_samples` (e.g. `model.tree_.n_node_samples[leaf_idx]`). `AttributeError: 'sklearn.tree._tree.Tree' object has no attribute 'n_samples'` means this mistake, not a missing installation.

## Champion Model — Required Script

The first time a task requires training the CatBoost Logloss champion model (Pipeline B, class-weighted), run this exact script, unmodified, before doing anything else for that question:

```python
import pandas as pd
import numpy as np
from catboost import CatBoostClassifier

train = pd.read_csv('data/german_train_pipelineB.csv')
val = pd.read_csv('data/german_val_pipelineB.csv')

X_train = train.drop(columns=['target_good'])
y_train = train['target_good']
X_val = val.drop(columns=['target_good'])
y_val = val['target_good']

cat_features = X_train.select_dtypes(include=['object']).columns.tolist()
counts = y_train.value_counts()
total_train = len(y_train)
weights = [total_train / (2 * counts[0]), total_train / (2 * counts[1])]

model = CatBoostClassifier(
    loss_function='Logloss', eval_metric='AUC', iterations=1000,
    learning_rate=0.05, depth=6, random_seed=42, use_best_model=True,
    class_weights=weights, cat_features=cat_features, verbose=False
)
model.fit(X_train, y_train, eval_set=(X_val, y_val))

results = model.get_evals_result()
train_logloss_final = results['learn']['Logloss'][-1]
val_logloss_final = results['validation']['Logloss'][-1]

val_probs = model.predict_proba(X_val)[:, 1]
train_probs = model.predict_proba(X_train)[:, 1]

np.save('champion_val_probs.npy', val_probs)
np.save('champion_train_probs.npy', train_probs)
y_val.to_csv('champion_y_val.csv', index=False)

print(f'train_logloss_final={train_logloss_final:.4f} val_logloss_final={val_logloss_final:.4f}')
```

Every subsequent question that references "the champion model" (confusion matrix, threshold sweep, metrics, SHAP) must load the saved arrays instead of retraining:

```python

import pandas as pd
val_probs = np.load('champion_val_probs.npy')
y_val = pd.read_csv('champion_y_val.csv')['target_good']
```

Do not retrain the model for these downstream questions under any circumstances. If `champion_val_probs.npy` does not exist yet, run the training script above first, exactly as written.

Before writing any code for a question that references "the champion model," first check whether `champion_val_probs.npy` already exists in the workspace:
